# 信号タイマー（traffic-light-timer）

信号機の切り替わる時間を提示する Web アプリです。GitHub Pages でそのまま動きます（ビルド不要・単一 HTML）。

## できること

- **残り秒数の提示**：青・黄・赤それぞれの長さと「青が始まった基準時刻」を設定すると、現在の色と、次に切り替わるまでの残り秒数を 0.2 秒間隔で更新して表示します。
- **歩行者信号の表示**：車両用に連動し、青の終わりは点滅として表示します（点滅の秒数は設定可能）。
- **同期ボタン**：実際の信号が青に変わった瞬間に「今、青になった」を押すだけで基準時刻を合わせられます。
- **観測モード**：切り替わった瞬間に色ボタンを押して記録すると、各色の長さと周期を推定し、設定へ反映できます。周期が分からない信号の実測用です。
- **複数信号の保存**：交差点ごとに名前を付けて保存できます（保存先はブラウザの localStorage のみ。外部送信なし）。
- **共有リンク**：設定を URL ハッシュに埋め込んだリンクを発行できます。

## 使い方

1. 青・黄・赤の長さ（秒）を入力する（分からなければ観測モードで測る）
2. 実際の信号が青に変わった瞬間に「今、青になった」を押す
3. 現在の色と残り秒数が自動で進みます

## 注意

実際の信号は時間帯・交通状況・感応式／系統式制御などで周期が変わる場合があります。本アプリの表示は設定した周期に基づく目安です。歩行・乗車中は画面ではなく実際の信号を確認してください。

## 構成

- `index.html` のみ（CSS・JS 内蔵、外部依存なし）
- GitHub Pages： リポジトリ Settings → Pages → Source を `main` ブランチ / ルートにすると公開されます
